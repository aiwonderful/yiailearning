# 任务：做一个单文件选题筛选工具

输入材料：同目录 topics.json、invalid-topics.json。域名 example.com 是占位符，不需要访问网页。

交付 topics.html，一个文件内包含 HTML/CSS/JavaScript。双击可在现代浏览器打开，无构建、无安装、无服务器、无联网依赖。

页面包含：选择 JSON 文件的原生文件输入、关键词输入框、清空查询按钮、结果数量、结果列表、错误提示。

规则：
1. 用户通过选择文件导入 UTF-8 JSON。不要用 fetch 读取同目录文件。
2. 顶层必须为数组，每个元素的 id/title/source 必须为非空字符串。无效时显示第几个记录及缺哪个字段；清空上一批结果，显示 0 条；不要让旧结果看起来是新导入成功。
3. source 去掉首尾空格后完全相同算重复，保留第一条；导入主题样本后为 2 条，保留 T1、T2。
4. 输入关键词后按 title 的子字符串匹配，忽略英文大小写和查询两端空格，不区分中文词边界。
5. 搜索不改动已导入数据。清空查询恢复全部去重后的记录。
6. 用户文本按普通文本显示，不作为 HTML 执行。
7. 解析失败显示可理解的错误，不留下旧结果。

验收：
- 首次打开显示“请选择 JSON 文件”或等价提示，不冒充已导入。
- 选 topics.json：2 条，T1/T2，T3 不出现。
- 输入 AI 编程：1 条，T1；输入 自媒体：1 条，T2。
- 输入 不存在的关键词：0 条，有无匹配说明；清空：2 条。
- 导入 invalid-topics.json：显示第 1 条缺少 source，列表为空。
- 再导入 topics.json：恢复 2 条。

请交付文件和实际执行的验证记录。未运行浏览器就明确写未运行，不得声称功能测试通过。
